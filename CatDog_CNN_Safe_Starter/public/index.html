How It Works

A classic CNN pipeline, end-to-end

01
🖼️

Image Input

Your image is resized to 128×128 pixels and normalised to [0, 1] pixel values.

02
🔬

Feature Extraction

Four Conv2D + BatchNorm + MaxPool blocks progressively extract edges, textures, and shapes.

03
🧮

Classification

A Dense layer with Dropout reduces to a single sigmoid neuron — 0 = cat, 1 = dog.

04
📊

Confidence Score

The raw sigmoid output is converted to a confidence percentage shown in the result.
